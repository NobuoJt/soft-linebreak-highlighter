# Soft Line Break Highlighter

Obsidianのライブプレビューモードで、Markdown的でない改行を強調表示するプラグインです。

## 概要

Markdownには2種類の改行があります：

- **ハード改行**：行末にスペース2つを追加してから改行する
- **ソフト改行**：末尾にスペース2つがない通常の改行

このプラグインは、Markdownで期待通りにレンダリングされない可能性があるソフト改行を視覚化するのに役立ちます。スペース2つで終わらない行の末尾に警告アイコン（⚠）を表示します。

## 機能

- **視覚的インジケーター**：Markdown的でない改行に警告アイコン（⚠）を表示
- **スマート除外**：ソフト改行が許容される特定のMarkdown要素を自動的に除外：
  - ヘッダー（H1-H6）
  - リスト項目（箇条書きと番号付き）
  - 引用ブロック
  - コードブロック
  - 水平線
  - テーブル行
  - 空行
- **控えめなデザイン**：警告アイコンは目立たず、執筆の流れを妨げません
- **ライブプレビューのみ**：Obsidianのライブプレビューモードでのみ動作

## インストール

### 手動インストール

1. [リリースページ](https://github.com/NobuoJt/soft-linebreak-highlighter/releases)から最新版をダウンロード
2. ファイルをObsidianプラグインフォルダに展開：`<vault>/.obsidian/plugins/soft-linebreak-highlighter/`
3. Obsidianを再読み込みするか、設定でプラグインを更新
4. 設定 > コミュニティプラグインでプラグインを有効化

### 開発

1. このリポジトリをクローン
2. `npm install`で依存関係をインストール
3. `npm run dev`でホットリロード付き開発を開始
4. `npm run build`で本番版をビルド

## 使用方法

インストールして有効化すると、プラグインは自動的にドキュメント内のソフト改行を強調表示します。Markdownの改行規則に従わない行の末尾に、小さなオレンジ色の警告アイコン（⚠）が表示されます。

### 強調表示される内容

- スペース2つで終わらない通常のテキスト行
- ソフト改行のある段落

### 強調表示されない内容

- スペース2つで終わる行（適切なMarkdown改行）
- ヘッダー（`# ## ###`など）
- リスト項目（`- * +`または`1. 2. 3.`）
- 引用ブロック（`>`）
- コードブロック（` ``` `）
- 水平線（`--- *** ___`）
- テーブル行
- 空行

## 設定

このプラグインは現在、設定オプションなしで動作します。将来のバージョンでは以下のカスタマイズオプションが含まれる可能性があります：

- 警告アイコンの外観
- カラースキーム
- 追加の除外ルール
